## 🎯 About DSAPTIQ

DSAPTIQ is an industry-grade experiential learning and placement-readiness platform designed to shift candidates from memorization to genuine algorithmic reasoning, visual understanding, and measurable skill progression.

### Core Architecture & Product Pillars

1. **Zero-Friction Learner Entry**:
   - Immediate access by entering a name, target track (Campus, Product, Service-Based, General), and experience level.
   - Anonymous persistence in `localStorage` backed by transferable access recovery codes (`DSAPTIQ-XXXX-2026`).

2. **100 Unique Daily MCQs Assessment Engine**:
   - 20 Quantitative Aptitude (Time & Work, Percentages, Train Speed, Probability, Mixtures)
   - 15 Logical Reasoning (Syllogisms, Blood Relations, Circular Seating, Coding-Decoding)
   - 10 Verbal & Analytical Ability (Grammar, Inference, Para-Jumbles, Vocabulary)
   - 20 Data Structures (Arrays, Linked Lists, Stacks, Queues, Heaps, BST, Tries, DSU, LRU)
   - 15 Algorithms & Complexity (Binary Search, Master Theorem, Kadane, Dijkstra, Lomuto, DP)
   - 10 Code Tracing & Logic (Loops, Recursion, Pointers, Bitwise Logic)
   - 10 Industry Application Scenarios (Distributed Locks, Redis Caching, DB Indexing, JWT, Kafka, Circuit Breakers)
   - 4 Modes: Practice (instant feedback), Challenge (timed exam), Revision, and Diagnostic.

3. **50 Solved Worked Examples**:
   - Structured 8-point pedagogical anatomy: Problem statement, tested concept, step-by-step reasoning, visual ASCII representation, verified final answer, common misconception alert, company hiring relevance, and related challenge.

4. **Logic Visualization Studio**:
   - **Binary Search Halver**: Animated search intervals, midpoint calculation, and half-space pruning.
   - **Data Structure Playground**: Interactive state mutations for Stacks (LIFO), Queues (FIFO), and Linked Lists (head/tail insert, delete, in-place reversal).
   - **Algorithm Sorting Animator**: Bar comparison scanner and element swap visualization.
   - **Code Tracing Lab**: Line-by-line code stepper with live stack variable watch tables and execution output.

5. **Placement Readiness Index (PRI)**:
   - Transparent, evidence-based readiness calculation:
     $$\text{PRI} = \sum_{i=1}^6 w_i s_i$$
     - Aptitude Proficiency: 25%
     - DSA & Algorithms: 30%
     - Logic & Code Tracing: 15%
     - Accuracy & Error Reduction: 10%
     - Timed Problem-Solving: 10%
     - Consistency & Improvement: 10%
   - Distinguishes **Provisional** (<20 attempts) from **Established** readiness scores, with actionable interventions and exportable printable candidate transcripts.

6. **Daily Bonus Wheel**:
   - One eligible spin every 24 hours with midnight reset countdown.
   - Rewards streak tokens, visual masterclasses, and revision points without artificially inflating academic PRI scores.
